# Banking Transaction Analysis using MySQL

## Project Overview
This project analyzes fictional banking transaction data using MySQL to understand transaction patterns, customer activity, payment channels, and transaction statuses.

## Tools Used
- MySQL
- MySQL Workbench

## Database Tables
- Branches
- Customers
- Accounts
- Transactions

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions
- JOINs
- Subqueries and CTEs
- CASE Statements
- Window Functions
- Date Functions

## Analysis Performed
- Transaction status analysis
- Monthly transaction trends
- Payment channel analysis
- Customer spending analysis
- Failed transaction analysis
- Customer ranking

## Project Files
- banking_transaction_analysis.sql
- advanced_banking_analysis.sql

## Dataset
This project uses fictional sample data created for learning and portfolio purposes. No real banking or customer information is used.

## Learning Outcomes
Practiced SQL queries, joins, aggregations, and advanced SQL techniques for data analysis.
